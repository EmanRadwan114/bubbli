# Bubbli

This repository contains the **frontend** of **Bubbli**, a modern full-stack gift store platform. The UI is built with React and focuses on performance, accessibility, and a smooth user experience.

---

## Features

- **Product Discovery:** Search by keyword, filter by price and type, and browse products by category.
- **Secure Authentication:** Email and Google sign-in with email account activation through verification links.
- **Session Security:** HTTP-only cookies for secure authentication and session management.
- **Flexible Payments:** Paymob online payments alongside Cash on Delivery.
- **Order Management:** Order tracking, order history, and email confirmations to keep users informed throughout the purchasing process.
- **Gift Recommendation Chatbot:** An interactive chatbot that helps users find suitable gifts based on their needs and preferences.
- **Product Reviews & Refunds:** One-review-per-product validation, along with order cancellation and refund request functionality.
- **Coupons & Discounts:** Coupon code support and discount handling during checkout.
- **Admin Dashboard:** Management of products, categories, orders, and coupons with real-time analytics and performance insights.

---

## Frontend Tech Stack

* **React**
* **React Router** – routing & navigation
* **React Query** – server state management
* **Context API** – global state management
* **Formik** – form handling
* **Yup** – form validation
* **Tailwind CSS** – styling

---

## Notes

* This repository contains **frontend only**
* It consumes REST APIs from the Bubbli backend
* Authentication relies on **HTTP-only cookies** handled by the backend
